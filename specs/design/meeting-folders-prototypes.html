Meeting folders

This page shows three designs for meeting folders on the Meetings page. Each design is a clickable prototype. The layout is the current layout: app menu, then the meeting rail, then the detail area. The designs differ in where the folder controls are and how the rail shows folders.

Rules in all variants

  • A meeting is in zero folders or in one folder.
  • Meetings with no folder show in the "Unfiled" group.
  • When a folder is selected, Start recording puts the new meeting in that folder. The rail shows the target folder.
  • A click on a folder opens the folder panel: name, description, facts and meetings.
  • You cannot delete a folder that holds meetings. Move or remove the meetings first.

Try these steps

  1. Click a folder. Read the folder panel.
  2. Keep the folder selected. Click Start recording, then click Stop.
  3. Open a meeting. Move it to a different folder.
  4. Try to delete a folder that holds meetings.
  5. Make a new folder. Rename it. Then delete it.

The window is 1080 px wide. On a small screen, scroll the window sideways.

Trade-offs

    Open point for all variants. When a meeting is open (no folder selected), the prototypes record into the folder of that meeting. Variant C records into the folder that is open in the rail. Decide which rule is correct.
